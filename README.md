# 📞 Визначення провайдера стаціонарного номера України

Статичний HTML-інструмент для визначення телеком-провайдера стаціонарного номера України за реєстром НКЕК.

**[▶ Відкрити →](https://YOUR_USERNAME.github.io/YOUR_REPO/)**

## Можливості

- Пошук за одним номером (всі формати: `0441234567`, `+380441234567` тощо)
- Пакетний режим — кілька номерів одразу
- Експорт результатів у CSV
- Історія запитів
- Без серверів, без реєстрації — все працює у браузері

## Дані

Реєстр первинного розподілу ресурсів нумерації НКЕК · **01.05.2026** · 8 216 записів

## Розміщення на GitHub Pages

1. Створіть новий репозиторій на GitHub
2. Завантажте `index.html` у корінь репозиторію
3. Зайдіть у **Settings → Pages → Source: Deploy from branch → main / (root)**
4. Через 1-2 хвилини сайт буде доступний за адресою:  
   `https://YOUR_USERNAME.github.io/YOUR_REPO/`

## Оновлення реєстру

1. Завантажте новий `.xls` з [nkek.gov.ua](https://nkek.gov.ua) (оновлюється щомісяця)
2. Скиньте файл у цей чат — отримаєте новий `index.html` з актуальними даними
